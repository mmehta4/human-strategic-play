Human Strategic Play Benchmark

How well can a model predict what real people actually choose in strategic games? Not what a rational agent would do, and not what an LLM thinks people do: the measured choices of thousands of humans.

The task

Each problem is a two-player game seen from one player's side: both payoff matrices, plus a plain-language description of the game. Predict the share of people who choose each action. Scored by cross-entropy, a strictly proper scoring rule, so the best strategy is to report your honest prediction.

Submit a model

  1. Get the data and splits from the repository: benchmark/data/.
  2. For every problem, predict under each protocol using only the allowed training data (see benchmark/data/splits.json).
  3. Score it yourself: python benchmark/score.py my_predictions.csv
  4. Open a pull request adding benchmark/submissions/your-model.json (created with --save), plus a link to your code or paper. LLM submissions must include the exact prompt.
